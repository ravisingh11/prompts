# Prompts

A personal prompt library for reusable AI workflows, review patterns, and repo-analysis routines.

## Contents

- `qa_prompt`: A multi-role repository QA workflow that separates discovery, planning, fixing, and reporting.

## Usage

Treat each prompt as a starting point. Review the instructions, adapt the scope to the repository or task, and remove any sections that do not apply before running it with an AI coding assistant.

## Notes

Prompts in this repository are working artifacts. They may be copied, modified, and tightened as better workflows emerge.
